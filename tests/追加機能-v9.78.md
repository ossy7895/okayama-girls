# 追加3機能 v9.78

## スコア入力練習モード

入口はホーム → スコアモード →「スコア入力を練習する」です。競技（野球9回／ソフトボール7回）と先攻・後攻を選び、新しく練習、または前回の続きを開きます。架空の12選手と初期スタメン9人を用意し、既存のスコア入力・走者・打点確認・オーダー変更・取消の操作を使います。茶色のバーと「練習モード｜公式成績には反映しません」で公式入力と区別します。「練習リセット」で初期状態へ戻せます。

練習は認証ユーザー別のsessionStorageへ保存し、同じブラウザのタブで再読込後に再開できます。タブを閉じる等で保存内容が失われる場合があり、別端末と同期する機能ではありません。保存できない場合は表示し、公式Firestoreへ代替保存しません。公式games・playerStatsへの書き込みとログ修正の経路を防止します。練習開始前の公式入力状態・選手一覧を保持し、終了時に元の状態へ戻します。

親子iframeメッセージに試合IDを付け、終了した練習から遅れて届いた状態で公式試合を更新しないようにします。初回スタメンは設定済みなので、すぐに打席や交代の練習を始められます。練習を終えてもホームの公式チーム・個人成績には追加されません。

## 観戦画面

入口はホーム → 観戦画面です。既存の管理者・メンバーログインが必要です。外部へ匿名公開したり、公開観戦URLを発行する機能ではありません。

既存gamesの更新が新しい30試合を購読し、選択した試合のイニング別得点、合計、表裏、B/S/O、塁上の走者、現在の自チーム打者または投手、最新40件のログを表示します。閲覧画面に記録を変更する操作はありません。既存Firestoreルールの読み取り権限をそのまま使い、ルールを緩和しません。接続できない場合は再接続案内を出し、最終保存日時を表示します。閲覧終了・ログアウト時は購読を解除して表示を消します。

公式入力では変更後1.2秒の待ち時間を置いて既存gamesへ自動保存します。入力が続く間はまとめ、同時に要求された保存は順番に処理します。作成中のプレー下書きは共有せず、確定済みの状態が対象です。手動保存も残し、終了時は保存成功を確認してから閉じます。通信エラー時は未更新と表示し、再接続時や手動保存で再試行できます。完全なオフライン保証や記録係の排他ロックは今回の対象ではありません。複数人が同じ試合を同時入力する運用は避けてください。

## 入金管理（管理者専用）

入口は管理者ホーム → 入金管理です。既存の非公開アルバムWorkerへ管理者専用APIを追加しています。**初回はCloudflare Workerのコード更新が必要**です。具体的な操作は [Worker手順](../cloudflare/album/README.md) を参照してください。

- 請求名、1人あたりの金額、期限、対象選手を指定して請求を作成します。
- 選手別に未入金・一部入金・入金済み、期限超過、残額を確認できます。
- 入金額、日付、現金／振込／その他、任意メモを記録します。複数回の分割入金ができます。
- 入金を訂正するときは理由を添えて取り消し、必要に応じて正しい入金を登録します。元の金額・操作日時・操作者・取消理由を残します。
- 請求は受付終了・再開できます。受付終了は請求や未入金の抹消ではありません。
- 一覧は25件ずつ読み込みます。「さらに読み込む」で追加し、総額は読込済みの請求に対する集計と明示します。

オンライン決済・銀行連携・自動引落・会計帳票発行はありません。入金の事実を管理者が確認して記録する台帳です。メンバーログインは共用アカウントのため、各家庭への個別請求公開は行いません。台帳データはブラウザの端末保存だけにはせず、毎回管理者認証を確認するWorkerと非公開R2で扱います。Firestore接続設定・認証方式・既存コレクション・ルールは変更していません。

## 検証

Node.jsで実際のHTMLフォーム・イベントハンドラー・親子iframeスコア処理を読み込み、簡易DOMと模擬通信で検証します。ブラウザの描画・実機タップ・本番Firebase/R2との結合試験の代替ではありません。本番データへの試験登録・削除・成績再集計は実施していません。

```sh
node tests/score.test.cjs
node --test --test-isolation=none tests/features.test.cjs
node --test --test-isolation=none cloudflare/album/worker.test.mjs cloudflare/album/client.test.mjs cloudflare/album/fees.test.mjs
```

確認対象は公式スコア196件、アルバム36件、追加画面28件、入金API15件、計275件です。練習データの公式保存防止、実際のiframe間のプレー反映、古いメッセージの拒否、元の公式状態の復元、保存順序、観戦の読み取り専用・購読解除、入金の権限・再送・過入金・競合・履歴保持を含みます。主画面の埋め込み画像25個・LIVE画像3個、守備選択の座標、下部ナビの素材・構造を維持しています。
